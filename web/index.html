Denoise 怎么用

放进图片就按「处理步骤」处理：默认只开 DRUNet 去噪，并且对所有图片生效。改了设置后点 对该图生效 只改当前这张，点 对所有图生效 改全部（之后加入的图也用它）。

步骤顺序：APISR 锐化 → DRUNet 去噪 → L0 平滑。APISR 会改变原有色彩；DRUNet 和 L0 不改颜色。

结果自动保存到输出文件夹（默认是程序目录下的 output，右上角可以改）。保护笔刷涂过的地方按比例换回原图，保存的就是你看到的。
